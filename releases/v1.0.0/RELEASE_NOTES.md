# xb_plugin v1.0.0 — 首次开源发布

本次发布包含两个可独立安装的 XBoard Telegram 插件：

- **TgAiAssistant v1.2.6**：AI 问答、知识库、群聊记忆、违规审核、编辑消息监听和管理员通知。
- **TgGroupCheckin v1.0.2**：私聊与群聊签到、随机流量奖励。

## 安装

下载本页面附件中对应插件的 `*-open-source.zip`，上传至 XBoard 后台插件页安装并启用。配置和运行要求见仓库内各插件 README。

本次两个安装包均为提供的原始开源压缩包，未重新打包；可使用附件 `SHA256SUMS.txt` 校验下载文件。
